### 1. Preguntas de investigación
1. ¿Qué tipo de problema podrías resolver consultando la documentación de GNS3?

Podría resolver problemas relacionados con la creación de topologías, configuración de dispositivos, conexiones entre routers y errores al iniciar o utilizar equipos virtuales.

2. ¿Qué diferencia existe entre la documentación de una herramienta y el repositorio de una biblioteca?

La documentación de una herramienta explica su funcionamiento, configuración y uso. En cambio, el repositorio de una biblioteca contiene su código fuente, ejemplos, versiones y reportes de errores.

3. ¿Qué información revisarías antes de utilizar una biblioteca de automatización?

Revisaría sus funciones, requisitos de instalación, compatibilidad con Python, dispositivos soportados, ejemplos de uso y documentación disponible.

4. ¿Por qué es importante comprobar qué plataformas y funciones admite una biblioteca?

Porque no todas las bibliotecas funcionan con los mismos dispositivos o sistemas. Verificar su compatibilidad permite evitar errores y elegir una herramienta adecuada para el proyecto.

5. ¿Cómo podrían utilizarse estos recursos en las siguientes prácticas?

Podrían utilizarse para solucionar errores en GNS3, mejorar los programas de Python y aprender a automatizar tareas de configuración y consulta de información de los dispositivos de red.

### 2. Recursos de investigación
## Documentación oficial de GNS3

https://docs.gns3.com/

Tema que aborda

Simulación y emulación de redes mediante GNS3.

Tipo de información que ofrece 

Guías de instalación, configuración, creación de topologías, conexión de dispositivos y solución de problemas.

Utilidad para el proyecto integrador

Permite configurar y comprobar el funcionamiento de la topología de red utilizada durante las prácticas.

Ejemplo de una situación

Cuando los routers R1 y R2 no logren comunicarse dentro de GNS3 y necesitemos revisar su configuración o conexiones

## Repositorio de Netmiko

https://github.com/ktbyers/netmiko

Tema que aborda

Automatización de dispositivos de red mediante Python.

Tipo de información que ofrece

Código fuente, instrucciones de instalación, ejemplos de conexión, funciones y dispositivos compatibles.

Utilidad para el proyecto integrador

Ayuda a conocer cómo automatizar consultas y comandos de administración en routers y switches compatibles.

Ejemplo de una situación

Cuando necesitemos desarrollar un programa en Python que se conecte mediante SSH a un router compatible para consultar su configuración.

## Solución de problemas de GNS3

https://docs.gns3.com/docs/troubleshooting-faq/troubleshoot-gns3

Tema que aborda

Identificación y solución de errores técnicos en GNS3.

Tipo de información que ofrece

Explicaciones sobre problemas de instalación, funcionamiento y configuración de GNS3.

Utilidad para el proyecto integrador

Facilita la identificación de errores que podrían impedir el funcionamiento del entorno de simulación.

Ejemplo de una situación 

Cuando GNS3 presente un error al abrir un proyecto o iniciar el programa y necesitemos investigar su causa.
